# 🎮 Tic Tac Toe – JavaScript Game

A simple and interactive **Tic Tac Toe game** built using **HTML, CSS, and Vanilla JavaScript**.  
This project focuses on **JavaScript logic, DOM manipulation, and event handling**.

---

## ✨ Features

- 2-player game (X vs O)
- Turn-based gameplay
- Win detection for all possible combinations
- Visual highlight for winning cells
- Reset functionality
- Clean and minimal UI

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
